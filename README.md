# ERP-Lite

Einzelplatz-ERP für Handel, Elektrotechnik und Sachverständigenleistungen (Österreich).
Eine Datei `index.html`, läuft im Browser (PC und Handy), Daten im OneDrive des Unternehmens.

- Funktionsumfang: siehe `PFLICHTENHEFT.md`
- Einrichtung PC/Handy und Microsoft-Anmeldung: siehe `ANLEITUNG-MOBIL.md`
- Veröffentlichung auf GitHub Pages: siehe `ANLEITUNG-GITHUB.md`

Dieses Repository enthält nur den Programmcode – keine Firmen- oder Kundendaten.
